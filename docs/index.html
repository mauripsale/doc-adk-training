🎓 Google ADK Training: From Zero to Hero 🚀

Welcome! This repository contains a comprehensive, multi-module training course for the Google Agent Development Kit (ADK). Through a series of hands-on modules, you will learn the core and advanced concepts of the ADK to build, test, deploy, and observe your own AI agents.

🎯 Our Philosophy: From Zero to Hero​

This course was born from a specific need: to create a complete learning path that takes a developer from the foundational concepts of AI agents to building complex, production-ready systems. The goal is to transform you from "Zero" to "Hero" in the world of AI Agent development with the Google ADK, providing not just the theory, but the hands-on practice required to become confident and proficient.

✍️ About the Author​

This course was created and is maintained by Maurizio Ipsale, a Google Cloud Authorized Trainer and Google Developer Expert (GDE) in AI and Cloud. This project stems from a passion for empowering developers with the skills needed to build the next generation of AI agents.

🚧 Project Status 🚧​

Current Version: v2.0.0 🎉

This repository is now a fully interactive, gamified Learning Management Platform & Training Course for the Google Agent Development Kit (ADK), covering the complete ADK 2.0 curriculum across 45 modules — from your first agent to distributed, enterprise-grade multi-agent systems with full AgentOps observability.

We continue to refine and expand the material as the ADK evolves. Your feedback and contributions are highly encouraged! If you find an issue or have a suggestion, please open an issue on GitHub.

🚀 What's New in v2.0.0 (Major Platform Release):​

  • 🧠 Interactive In-Doc Knowledge Checks (KnowledgeCheck): Embedded concept quizzes with Socratic feedback, misconception breakdowns, guided hints, dynamic option shuffling (Fisher-Yates), and reflection cooldowns to prevent brute-forcing.
  • 🏆 Student Progress Tracker & Gated Completion: Real-time completion tracking with interactive checklist drawer in the navbar, multi-tab sync, and atomic progress reset engine.
  • 📜 Official Student Completion Certificate: In-app verification modal and instant vector/canvas PDF export with custom learner name, date, verification ID, and credential checklist.
  • 🔒 Interactive Solution Vault (SolutionVault): Collapsible encrypted solution reveals with fast completion prompt, dedicated workshop facilitator support, and WCAG AAA high-contrast light mode styling.
  • 🔍 Instant Offline Local Search: Integrated full-text offline search bar across all 45 modules powered by @easyops-cn/docusaurus-search-local.
  • 🤖 Automated Student Grader (adk-student-evaluator): Zero-cost empirical verification framework that simulates student lab executions and audits code syntax against real ADK runtimes.
  • ⚡ Zero-Setup Cloud Onboarding: 1-click cloud launch buttons for GitHub Codespaces, Google Cloud Shell, and VS Code DevContainers with pre-configured Python 3.11, uv, and GCP tooling.
  • ⚡ Full ADK 2.0 API Alignment: Comprehensive coverage of Human-in-the-Loop (HITL), Context Caching & Compaction, Session Rewind, Callbacks, and Custom Plugins with zero inline code spoilers in student lab challenges.

⏱️ Time Estimation​

This comprehensive training course is designed for both self-service and instructor-led delivery. The estimates below provide a realistic guide for pacing, considering the technical depth and hands-on nature of the labs.

  • 🧑‍💻 Self-Service (SS) Duration: This estimate reflects the time a motivated individual learner would take to read the theory, complete the labs, and account for a 25% troubleshooting/review factor.
  • 👨‍🏫 Instructor-Led Training (ILT) Duration: This estimate is tailored for a classroom environment (up to 16 participants) with a net delivery time of 6 hours per day. It includes a 75% buffer for instructor guidance, Q&A, and assisting students during labs, plus a 5-minute transition buffer between modules.

⏱️ Course Outline​

🌱 Part 1: Foundations (Modules 1-7)​

This part covers the absolute basics of AI agents and the ADK, getting your environment set up and guiding you through building and running your first agents, including multimodal capabilities.

  • 📖 Module 1: Introduction to AI Agents & Google ADK (🧑‍💻 35 min / 👨‍🏫 55 min)
  • 📖 Module 2: Setting Up Your Development Environment (🧑‍💻 40 min / 👨‍🏫 60 min)
  • 📖 Module 3: Your First Agent: The "Echo" Agent (🧑‍💻 35 min / 👨‍🏫 55 min)
  • 📖 Module 4: Core Agent Concepts: LlmAgent Deep Dive (🧑‍💻 30 min / 👨‍🏫 50 min)
  • 📖 Module 4.5: Professional Model Configuration, Resiliency & Portability (🧑‍💻 30 min / 👨‍🏫 45 min)
  • 📖 Module 5: Running and Interacting with Agents (🧑‍💻 30 min / 👨‍🏫 50 min)
  • 📖 Module 6: Running an Agent Programmatically (🧑‍💻 35 min / 👨‍🏫 55 min)
  • 📖 Module 7: Multimodal and Images 📸 (🧑‍💻 40 min / 👨‍🏫 60 min)

🛠️ Part 2: Tools & Capabilities (Modules 8-14)​

This part focuses on giving your agents "superpowers" by connecting them to tools, from built-in capabilities to custom functions and third-party libraries.

  • 🧰 Module 8: Introduction to Tools (🧑‍💻 35 min / 👨‍🏫 55 min)
  • 🧰 Module 9: Intro to Custom Function Tools (🧑‍💻 45 min / 👨‍🏫 70 min)
  • 🧰 Module 10: Stateful Tools & ToolContext (🧑‍💻 40 min / 👨‍🏫 65 min)
  • 🧰 Module 11: OpenAPI Tools (🧑‍💻 35 min / 👨‍🏫 55 min)
  • 🧰 Module 12: Built-in Tools and Grounding (🧑‍💻 30 min / 👨‍🏫 45 min)
  • 🧰 Module 13: Advanced Interactions: Actions & HITL (🧑‍💻 40 min / 👨‍🏫 65 min)
  • 🧰 Module 13.5: Extending ADK - Custom Persistence with Firestore (🧑‍💻 30 min / 👨‍🏫 45 min)
  • 🧰 Module 14: Third-Party Tools (🧑‍💻 30 min / 👨‍🏫 40 min)

🤖🤖 Part 3: Multi-Agent Systems (Modules 15-21)​

Learn how to go beyond single agents and build complex systems where multiple agents collaborate to solve complex problems using ADK 2.0 Graph-based Workflows.

  • 🤝 Module 15: Introduction to Multi-Agent Systems (🧑‍💻 15 min / 👨‍🏫 30 min)
  • 🤝 Module 16: Static Orchestration (🧑‍💻 40 min / 👨‍🏫 60 min)
  • 🤝 Module 17: Structured Routing (🧑‍💻 30 min / 👨‍🏫 45 min)
  • 🤝 Module 18: Dynamic Orchestration (🧑‍💻 40 min / 👨‍🏫 65 min)
  • 🤝 Module 19: Collaborative Teams (🧑‍💻 45 min / 👨‍🏫 75 min)
  • 🤝 Module 20: Cyclic Workflows (🧑‍💻 40 min / 👨‍🏫 65 min)
  • 🤝 Module 21: Distributed Graphs (🧑‍💻 50 min / 👨‍🏫 70 min)
  • 🏁 Module 21.5: MAS Knowledge Milestone (🧑‍💻 15 min / 👨‍🏫 30 min)

🏭 Part 4: Production Readiness (Modules 22-26)​

This part covers the essential features for making your agents robust, observable, and reliable in a production environment.

  • 🧠 Module 22: State and Memory (🧑‍💻 35 min / 👨‍🏫 55 min)
  • 📦 Module 23: Artifacts (🧑‍💻 40 min / 👨‍🏫 65 min)
  • 🧪 Module 24: Evaluation (🧑‍💻 50 min / 👨‍🏫 75 min)
  • 📊 Module 25: Observability (🧑‍💻 35 min / 👨‍🏫 55 min)
  • 🦺 Module 25.5: Responsible AI (RAI) & Safety Plugins (🧑‍💻 35 min / 👨‍🏫 55 min)
  • 🛡️ Module 26: Callbacks (🧑‍💻 40 min / 👨‍🏫 65 min)

🔌 Part 5: Advanced Integrations & UI (Modules 27-30)​

This section covers advanced tooling with the Model Context Protocol (MCP) and strategies for integrating your agents with user interfaces.

  • 🔗 Module 27: Introduction to MCP (🧑‍💻 40 min / 👨‍🏫 65 min)
  • 🔗 Module 28: Building MCP Tools (🧑‍💻 40 min / 👨‍🏫 65 min)
  • 🖼️ Module 29: UI Integration Intro (🧑‍💻 35 min / 👨‍🏫 55 min)
  • 🖼️ Module 30: Custom Streaming Client (🧑‍💻 45 min / 👨‍🏫 65 min)

☁️ Part 6: Deployment & Enterprise (Modules 31-36)​

Learn how to deploy your agents and their components to various scalable cloud environments, including enterprise-grade platforms.

  • 🚀 Module 31: Production Deployment Strategies (🧑‍💻 15 min / 👨‍🏫 25 min)
  • 🚀 Module 32: Deployment to Cloud Run (🧑‍💻 35 min / 👨‍🏫 50 min)
  • 🚀 Module 33: Deployment to GKE (🧑‍💻 60 min / 👨‍🏫 95 min)
  • 🚀 Module 34: Deploying an MCP Server to Cloud Run (🧑‍💻 70 min / 👨‍🏫 105 min)
  • 🚀 Module 35: Deployment to Agent Runtime (🧑‍💻 60 min / 👨‍🏫 90 min)
  • 🚀 Module 36: Gemini Enterprise (🧑‍💻 15 min / 👨‍🏫 25 min)

🏆 Part 7: Capstone Project & Best Practices (Modules 37-40)​

Apply everything you've learned in a final capstone project, review essential best practices for building production-ready agents, and explore advanced extensibility patterns like plugins and skills before tackling a full enterprise-grade capstone.

  • ✨ Module 37: Advanced Personalized Shopping Agent (🧑‍💻 85 min / 👨‍🏫 120 min)
  • ✨ Module 38: Best Practices (🧑‍💻 35 min / 👨‍🏫 50 min)
  • 🔌 Module 39: ADK Plugins (🧑‍💻 35 min / 👨‍🏫 50 min)
  • 🎓 Module 39.5: Agent Skills (🧑‍💻 35 min / 👨‍🏫 50 min)
  • 🎯 Module 40: Advanced Capstone - Aegis Incident Response & AgentOps (🧑‍💻 100 min / 👨‍🏫 140 min)

▶️ Getting Started​

⚡ 1-Click Cloud Workspace (Zero Setup)​

Get started immediately without installing Python, Docker, or Google Cloud SDK on your machine:

  • — Launches a full cloud VS Code environment with Python 3.11, uv, gcloud, and all dependencies pre-installed.
  • — Clones and opens the project directly in Google Cloud Shell.

🐳 VS Code DevContainer (Local Docker)​

  1. Open the repository in VS Code with Docker Desktop running.
  2. Click "Reopen in Container" when prompted.

💻 Standard Local Setup (uv)​

Before you begin, please ensure you have the following prerequisites installed:

  • Git
  • Python 3.11+
  • A Google Cloud Project with billing enabled
  • The Google Cloud CLI (gcloud)

To get started with the course:

  1. Clone the repository: git clone https://github.com/mauripsale/doc-adk-training.git
  2. Navigate to the directory: cd training
  3. Begin with Module 1 and proceed through the modules in order. Each lab builds upon the concepts and code from the previous one.

Happy building!
