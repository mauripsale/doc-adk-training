Variant A: 1-Day Workshop (ILC)

Total Estimated Duration: 355 minutes / 5.92 hours

This workshop is a focused, high-impact training variant designed to provide a self-contained, hands-on learning experience. The modules selected represent the absolute "critical path" to agent development, taking a developer from zero to being able to build a useful, tool-powered agent within a single day, now including an essential overview of the Model Context Protocol (MCP).

ModuleInclude? (YES/NO)Justification for Inclusion/Exclusion
Module 1: Introduction to AI Agents & Google ADKYESEssential foundational theory on what agents are and why the ADK is used.
Module 2: Setting Up Your Development EnvironmentYESCritical hands-on step; participants cannot proceed without a working environment.
Module 3: Your First Agent: The "Echo" AgentYESCore practical skill: building and running a basic agent.
Module 4: Core Agent Concepts: LlmAgent Deep DiveYESFoundational skill: controlling agent behavior via instructions is non-negotiable.
